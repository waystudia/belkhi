# Пошаговое создание тендера

Маршрут `#new`: работа → параметры → место и сроки → фото → проверка.
Категории: строительство дома, фундамент, кровля, электромонтаж, отделка.
Параметры фундамента зависят от подтипа: лента, плита, сваи.
Технические значения необязательные, без инженерных значений по умолчанию.
Заказчик может попросить замер. Введённые параметры показываются в тендере
и в откликах. Точный адрес не запрашивается в публичном объявлении.

Черновик хранится в accountStorage `belkhi-tender-draft-v2`.
Фото сохраняются в памяти до публикации; после перезагрузки требуется
прикрепить заново, о чём форма предупреждает. Опубликованный тендер и файлы
сохраняются в существующем IndexedDB этого устройства. Это демонстрационный
локальный сценарий, облачная публикация здесь не добавлена.

В демопрофиле доступны роли «Заказчик / Специалист»; переключатель не меняет
роли авторизованного аккаунта. Лента содержит отдельные действия
«Открыть тендер» и «Откликнуться». Для отправки отклика нужен профиль мастера.

## Основания UX

Использован общий пошаговый сценарий объявления, без копирования тарифов:
- Авито, официальный ролик: https://www.youtube.com/watch?v=S2QoGQgokek
- ТЕХНОНИКОЛЬ, исходные параметры кровли: https://nav.tn.ru/services/proektno-raschetnyy-tsentr/raschet-krovli/
- IEK, исходные данные электромонтажа: https://www.iek.ru/company/blog/sborka-bazovogo-shchita-av-vdt-poshagovo-br-chast-1-podbor-oborudovaniya/

Макет создан встроенным Imagegen: `output/imagegen/tender-flow-reference.png`
(локальный артефакт, не ресурс приложения). Промпт: белый интерфейс Белхи,
цвета #14291f/#00843d/#e5f4e8, компактные поля и овальные кнопки; парные
экраны ПК/телефона для работы, места, фото, деталей и отклика. Пятишаговая
логика реализации имеет приоритет над ошибочной подписью «4 шага» в макете.

## Проверка

`tests/tender-wizard.cjs` использует Playwright, PLAYWRIGHT_MODULE и
CHROMIUM_PATH. Проверяет пять категорий, ветки фундамента, валидацию,
возврат/перезагрузку, файлы, публикацию/чтение параметров, роли и ленту
при ширинах 319/390/768/1440 px. По умолчанию URL http://127.0.0.1:4182/;
публичный URL можно передать первым аргументом.
